> 단계: 자동 검증

1. `verify-agent`에게 테스트, 타입 검사, ESLint, Playwright, Sentry 검증을 맡긴다.
2. 실패가 있으면 분류표대로 회귀 단계를 사용자에게 알리고 멈춘다.
3. 모두 통과하면:
   - 로컬 개발 서버를 백그라운드로 실행한다(`npm run dev` 등 프로젝트 명령).
   - 접속 주소와, Spec 인수 조건에서 뽑은 확인 시나리오 체크리스트를 사용자에게 준다.
   - "직접 써 보시고 부족한 점을 말씀해 주세요"로 마무리한다.

사용자가 피드백을 주면 `docs/feedback/FEEDBACK.md`에 날짜와 함께 적고, CLAUDE.md의 단계 판별표로 각 항목을 분류해 알려 준다.
