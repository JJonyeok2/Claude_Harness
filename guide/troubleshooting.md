# 문제 해결

## 설치

**`git 저장소가 아닙니다`**
대상 폴더에서 `git init`을 먼저 실행하세요.

**설치했는데 훅이 안 돌아요**
```bash
git config core.hooksPath          # .githooks 가 나와야 함
ls -l .githooks                     # 실행 권한(x) 확인
chmod +x .githooks/* scripts/*.sh
```

**일부 파일이 "건너뜀(이미 있음)"으로 나와요**
같은 이름의 파일이 이미 있어서 덮어쓰지 않은 것입니다. 기존 `CLAUDE.md`가 있었다면 하네스 내용을 직접 합쳐 주세요.

## 커밋

**`git user.name 이 '...' 입니다`로 막혀요**
```bash
git config user.name JJonyeok
```

**커밋 메시지에 금지어가 없는데 막혀요**
`codex`, `gemini`, `gpt-4` 같은 도구 이름도 금지어입니다. 문구를 바꾸거나 [금지어를 조정](customizing.md#커밋-메시지-금지어)하세요.

**시크릿이 아닌데 시크릿으로 잡혀요**
일반 패턴(`password = "..."`)이 테스트 픽스처를 잡는 경우가 많습니다.
- 테스트 값은 12자 이하로 두거나, 환경 변수로 읽게 바꾸는 것을 먼저 권합니다.
- 그래도 필요하면 `check-secrets.sh`의 제외 목록(`case "$f" in ...`)에 해당 경로를 추가하세요.

**급하게 훅을 건너뛰고 싶어요**
`git commit --no-verify`로 Git 훅은 건너뛸 수 있지만, 시크릿이 없다는 것을 직접 확인한 경우에만 쓰세요. Claude Code의 가드 훅은 이 방법으로 건너뛸 수 없습니다.

**가드 훅이 매번 막아요**
Python 3와 Node.js가 모두 없으면 훅이 명령을 읽지 못합니다. 둘 중 하나를 설치하세요.

## 오케스트레이터

**`/run`이 Spec에서 넘어가지 않아요**
Spec 승인을 기다리는 중입니다. "승인", "이대로 진행해" 같이 답해 주세요.

**같은 Task에서 계속 FIX가 나요**
2회를 넘으면 자동으로 멈춥니다. `/status`로 QA 지적 내용을 확인하고, Task가 너무 크면 `/task`로 다시 나누거나 Spec이 애매하면 `/spec`으로 돌아가세요.

**세션이 끊겼어요**
`/run`을 인자 없이 치면 `docs/STATE.md`를 보고 이어서 진행합니다.

**`/status`가 "멈춤 의심"이라고 해요**
서브에이전트가 30분 넘게 기록을 남기지 않은 경우입니다. 실제로 오래 걸리는 작업일 수 있으니 터미널 진행 상황을 먼저 보고, 멈춘 것이 맞으면 `/run`으로 재개하세요.

## 병렬 실행

**병렬 그룹을 합칠 때 충돌이 나요**
Task 에이전트의 예상 수정 파일이 실제와 달랐던 경우입니다. 오케스트레이터가 멈추고 충돌 파일을 알려 줍니다. 해당 Task들을 순차로 바꾸고 다시 진행하세요.

**사용량 한도에 금방 닿아요**
동시 실행 수를 2나 1로 줄이세요. [병렬 한도 바꾸기](parallel-execution.md#한도-바꾸기)

## 피어 리뷰

**Computer Use가 앱을 못 찾아요**
Claude Code에서 Computer Use 접근 권한에 Codex와 Antigravity가 허용돼 있는지 확인하세요.

**리뷰어가 파일을 바꿔서 멈췄어요**
하네스는 자동으로 되돌리지 않습니다. `git diff`로 바뀐 내용을 확인한 뒤 직접 되돌리거나 남길지 정하세요.

**Codex가 로그인 화면에서 멈춰요**
로그인은 Claude가 대신하지 않습니다. 미리 로그인해 두세요.

## 자동 검증

**Playwright, ESLint가 "건너뜀"으로 나와요**
프로젝트에 설치돼 있지 않은 경우입니다. [시작하기](getting-started.md#검증-도구-설치-처음-한-번)를 참고해 설치하세요.

**Sentry 확인 불가**
Sentry MCP나 `sentry-cli`가 없으면 건너뜁니다. 인증 토큰은 `.env`에만 두고, `.sentryclirc`는 `.gitignore`에 들어 있습니다.
